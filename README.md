## ▶️ How to Run the Programs

1. Clone this repository:

   ```bash
   git clone https://github.com/CodeWithRamyaa/python-dsa-practice.git
   ```

2. Navigate to the repository folder:

   ```bash
   cd python-dsa-practice
   ```

3. Run any Python program:

   ```bash
   python linear_search.py
   ```

   Replace `linear_search.py` with the filename you want to execute.

**Requirement:** Python 3 must be installed on your computer.
