## ▶️ How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/CodeWithRamyaa/python-dsa-practice.git
   ```

2. Open the project folder:

   ```bash
   cd python-dsa-practice
   ```

3. Run any Python program:

   ```bash
   python filename.py
   ```

   Replace `filename.py` with the program you want to execute.
